# Changelog

## 0.1

- First release.
- Live Technitium stats, queries-per-minute chart (or per hour for 24 hours), and top clients, domains and blocked domains.
- Alerts for retry storms, SERVFAIL, query spikes, rate-limited clients, slow DNS answers and an unreachable API.
- DNS answer-time and API health checks.
- API token encrypted with Windows DPAPI; runs without admin rights.
